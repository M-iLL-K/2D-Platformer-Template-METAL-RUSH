# 講師示範清單：沒碰過 Godot 的學員要看到哪些操作

照順序示範，每一項都是「做一次給他們看，再讓他們自己做一次」。
標 ⚠ 的是不講一定會有人舉手的地方。標「課前確認」的是 4.7.2 介面用字或行為沒有實機核對過，請先自己點一次。

學員要查的內容都在根目錄：快捷鍵、訊號、函式、每張卡怎麼操作在 `速查表.md`；東西在哪個資料夾、每個零件的
設定、按鍵設定、房間在 `零件手冊.md`。示範時不用背，指給他們看就好。

---

## A. 開場導覽（約 10 分鐘，逛展示間之前）

### A1. 認識五個區域（2 分鐘）

| 區域 | 一句話 |
|---|---|
| 左下「檔案系統」 | 倉庫，所有能拖的東西都在這裡 |
| 左上「場景」樹 | 你的關卡裡有什麼 |
| 中間畫面 | 關卡長怎樣 |
| 右邊 Inspector | 選到的東西的設定 |
| 下方「輸出」 | 系統跟你講話的地方 |

- ⚠ 畫面最上方要切到 **2D** 分頁。有人一打開停在 3D 或 Script，會以為壞了。
- 課前確認：教室電腦的 Godot 介面是中文還是英文，全班統一會比較好帶。

### A2. 移動畫面（1 分鐘）

- **按住滑鼠中鍵拖曳**：平移畫面
- **滾輪**：縮放
- 在場景樹選一個節點，滑鼠移到中間畫面按 **F**：畫面跳到那個節點（找不到東西時很好用）

### A3. 開場景、執行、停止（2 分鐘）

- 檔案系統**雙擊** `.tscn` 打開場景
- **F6** 執行目前場景，**F8** 或關掉視窗停止
- ⚠ **不要按 F5**。F5 跑的是「主場景」，第一次按會跳出選主場景的對話框，新手會卡住（README §4 才教設主場景）

示範：打開 `levels/Showroom.tscn` 按 F6，接著讓學員自己逛展示間。

### A4. 看輸出面板（1 分鐘）

- 所有「放錯位置、沒連線、按鍵撞在一起」都會在這裡印**中文**提示
- 照唸：「輸出面板的紅字不是你把遊戲弄壞了，是系統在告訴你放錯籃子了。」
- 養成習慣：**沒反應先看輸出，看不懂再舉手**

## B. 組玩具箱之前（約 15 分鐘）

### B1. 另存到 `_my/`（3 分鐘，最重要）

1. 打開 `levels/_starts/W1_ToyBox.tscn`
2. **場景 → 另存場景為**（Scene → Save Scene As）→ 選 `_my/` → 存檔
3. 確認分頁上的路徑是 `res://_my/...`

- **Ctrl+S** 存檔。分頁名稱旁邊有 `(*)` 就是還沒存
- 讓每個人當場做一次。這是之後五週每週都要用的動作

### B2. 復原、刪除、複製、改名（1 分鐘）

**Ctrl+Z** 復原、**Delete** 刪除、**Ctrl+D** 複製、**F2** 改名。講完「弄錯了就 Ctrl+Z」，學員會比較敢亂試。

### B3. 拖一張卡進籃子（2 分鐘）

1. 從檔案系統把抽到的卡（`mechanics/` 裡的 `.tscn`）拖到場景樹的 **Player → Mechanics** 上
2. F6，輸出面板印出「已啟用」

- ⚠ **故意示範拖錯一次**：拖到關卡根節點，讓大家看黃色中文警告長什麼樣子。示範過一次錯誤，之後舉手會少很多
- 三個籃子：`Mechanics`（機制卡）、`Juice`（手感）、`Abilities`（攻擊能力）；零件直接放關卡底下

### B4. Inspector 調數值（2 分鐘）

- 拉一次拉桿、選一次下拉、勾一次勾選框
- ⚠ **滑鼠停在欄位名稱上會出現中文說明**。不講，大部分人不會發現
- `enabled` 取消勾選 = 暫時關掉這張卡，想比較有沒有差時用，不用刪掉
- **調玩家本身**：在場景樹點 **Player**，Inspector「移動參數」有跑速 `move_speed`、跳多高 `jump_force`、
  重力 `gravity`、地面摩擦 `ground_friction`。跟機制卡是疊加的（卡片是在這些數值上再乘倍率）
- ⚠ 講清楚差別：在**關卡裡點 Player** 調數值是安全的，只存在自己的關卡檔；點 Player 旁邊的**場記板圖示**
  進到 `Player.tscn` 裡改才會改到唯讀區

### B5. 擺零件（1 分鐘）

- 從 `blocks/` 拖一個零件（例如 `Box`）進關卡，在中間畫面用滑鼠拖到想要的位置
- 課前確認：把 `.tscn` 直接拖進**中間畫面**時，會掛在場景樹的哪一層。決定要教「拖到畫面上」還是「拖到場景樹再移位置」，全班統一一種

### B6. 開格線吸附（1 分鐘）

- 中間畫面上方工具列打開**格線吸附**（Use Grid Snap），**吸附選項 → 設定吸附**（Configure Snap）把格線步長設成 **16 × 16**
- 這個設定存在每台電腦上，**每個人都要自己設一次**
- 課前確認：中文介面的選單用字

### B7. 畫地形（3 分鐘）

1. 場景樹點 `TileMapLayer`，下方面板會切到 TileMap 編輯器
2. 在磚塊清單選一塊磚
3. 中間畫面：**左鍵畫、右鍵擦**
4. 工具列換**矩形工具**，拉一下就是一整片地板或牆（最省時間，一定要教）

- 專案的磚塊每一塊都是實心的，畫下去就能踩，一格一格畫就好
- ⚠ **選著 `TileMapLayer` 時，在畫面上點一下就是畫磚**。學員想去拖箱子，結果在箱子上畫了一格磚。講法：「畫完地形，先在場景樹點別的節點，再去動其他東西。」
- ⚠ 不要把磚畫在玩家出生點或 Room 的黃點（重生點）上，不然一開場或一重生就卡在牆裡
- 單向平台不是磚，是 `blocks/OneWayPlatform`，要用拖的

### B8. 訊號連接（2 分鐘，01d 規定的示範）

1. 擺一個 `Button`、一個 `Door`
2. 選按鈕 → 右邊 Inspector 旁邊的「**節點**」分頁 → 雙擊 `turned_on` → 選門 → 函式選 `activate` → 連接
3. 指出畫面上出現的**黃色虛線**：「有線就是連好了」
4. F6，踩按鈕門就開

- 要觸發什麼，只由訊號決定。能連哪些訊號、哪些函式，全部列在 `速查表.md` §2、§3
- 課前確認：連線對話框的函式清單很長，勾「只顯示腳本方法」之類的選項可以縮短。確認 4.7.2 的選項名稱

## C. 組玩具箱時，有人問再教

### C1. 調血量（1 分鐘）

範本已經放好 `ValueSettings_Health`：拉 `start_value`、`max_value`；`show_in_hud` 打勾一開場就顯示血條。
其他數值（金幣、分數…）再拖一個 `blocks/ValueSettings.tscn`，`kind` 打名字（全專案唯一要打字的地方）。

### C2. 按鍵設定（3 分鐘）

範本已經放好 `KeySettings`：

- **改基本操作**：Inspector「預設操作」下拉選新的鍵，`None` = 不改，方向鍵永遠能用
- **加自己的按鍵**：示範「按 F 玩家會死」（成品在 `tests/blocks/KeyKillDemo.tscn`）
  1. 把 `blocks/KeyTrigger.tscn` 拖到 **KeySettings 底下**，改名 `Key_F_Die`
  2. `key` 選 F、`trigger` 選「按下時」
  3. 節點分頁 → 雙擊 `triggered` → 選 Player → 函式選 `kill`
- 一句話：「**Inspector 設定什麼時候，訊號決定做什麼。**」
- ⚠ 不要去改「專案設定」裡的 Input Map，那個重灌會被蓋掉
- ⚠ 選到跟卡片一樣的鍵（重力翻轉、忽大忽小、衝刺預設都是 Shift，近戰是 F），輸出面板會提醒，換一顆就好

### C3. 攝影機

- `Camera2D` 的位置決定畫面對準哪裡；場景裡有 Room 時，鏡頭會自動跳到房間中心，不用調位置
- 縮放：Camera2D 的 `zoom`，**x 和 y 要填一樣的數字**（小於 1 看得比較遠，大於 1 放大）
- 這是目前唯一要打數字的地方。之後如果做了 `zoom_level` 拉桿，就改教拉桿

## D. 之後的週次再教

| 什麼時候 | 內容 |
|---|---|
| 關卡比一個畫面大時（W2） | **Room**：README §5.1。`_Template` 已經放好 Room1，Ctrl+D 複製往旁邊拖、邊貼齊 |
| 想要「某件事發生時做某事」 | **EventListener**：下拉選事件（玩家死亡時、進入房間時…），`triggered` 連到零件 |
| 想換外觀（W4） | 拖 `skins/Skin` 到零件底下、圖拖進 `texture_normal`；沒有圖用 `art/blocks_skin/` 講師畫的；完整流程看 `零件手冊.md` §7 和練習關（`_help/練習關解答.md`） |
| 最後一週 | 匯出網頁版：README §8 |

## 禁區：一開始就要講

- ⚠ **不要點 Player 旁邊的場記板圖示**（在編輯器中開啟），也**不要勾「可編輯子節點」**（Editable Children）：會改到唯讀區的 `player/Player.tscn`，重灌時會不見
- ⚠ **不要打開 `.gd` 檔**。雙擊到了會跳到 Script 分頁，點上方的 **2D** 回來
- ⚠ **不要存檔到 `_my/` 以外的地方**
- 照唸：「`player/`、`autoload/` 這些資料夾是唯讀的，你的東西全部存在 `_my/`。真的弄得很亂，複製一份新的 `_my/` 重來就好，不會壞到別人。」
