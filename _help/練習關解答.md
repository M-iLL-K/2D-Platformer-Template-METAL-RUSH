# 練習關解答：W3_JuicePractice、W4_SkinPractice

給講師和助教巡場時對照，不會發給學員（`_help/` 是 `export-ignore`）。
學員版只寫「告示牌檢查什麼、常見卡住」，在 `零件手冊.md` §8。這份是完整的操作步驟。

**每次都先做**：打開練習關 →「場景 → 另存場景為」存到 `_my/`（例如 `_my/MySkinPractice.tscn`）→ 之後都改這一份。
做完一題按 F6，**一定要在練習關的分頁按**。告示牌開場 0.3 秒後檢查，輸出面板會列出每一題完成了沒。

學員舉手說「做了沒變綠」時，先看三件事：改的是不是 `_my/` 那份、F6 是不是在練習關的分頁按、自己的 HUD／選單場景有沒有存檔。

## W3：手感果汁

Juice 都拖到 **Player → Juice** 底下（`juice/` 資料夾）。

### 1. 落地時畫面震一下
1. 從 `juice/` 拖 `Juice_ScreenShake` 到 Player → Juice
2. 不用改設定，`timing` 預設就是「落地時」

### 2. 跳的時候有聲音
1. 拖 `Juice_Sound` 到 Player → Juice
2. 不用改設定，`timing` 預設「跳躍時」、`sound` 預設「跳躍」

### 3. 撿金幣時噴星星
1. 拖 `Juice_Particles` 到 Player → Juice
2. `timing` 選「撿到東西時」，`style` 選「星星」

### 4. 撿金幣時叮一聲
1. **再拖一個** `Juice_Sound`（不要改第 2 題那個）
2. `timing` 選「撿到東西時」，`sound` 選「金幣」

### 5. 震得更用力
1. 點第 1 題的 `Juice_ScreenShake`
2. `strength` 拉到 8 以上

### 6. 打倒敵人時畫面停一下
1. 拖 `Juice_HitStop` 到 Player → Juice
2. `timing` 選「打倒敵人時」
3. F6 後按 **F** 攻擊，把敵人打倒試試

### 7. 踩按鈕時鏡頭推近
1. 拖 `Juice_CameraZoom` 到 Player → Juice，`timing` 選「**不自動觸發**」
2. 在場景樹選關卡裡的 `Button`（在 Room1 底下）
3. Inspector 旁邊的「**節點**」分頁 → 雙擊 `turned_on` → 選 `Juice_CameraZoom` → 函式選 `play` → 連接
4. 畫面上出現黃色虛線就是連好了

### 8. 撞牆時播自己的音效
1. 再拖一個 `Juice_Sound`
2. `timing` 選「撞牆時」，`sound` 選「自訂」
3. 出現 `custom_sound`：從檔案系統把音檔拖進去（學員沒有音檔的話，先拖 `sfx/` 裡任何一個示範）

## W4：套皮與 UI

**再製範本**：檔案系統裡對範本按右鍵 →「再製」→ 取名 → 新檔會出現在範本旁邊，**把它拖進 `_my/` 資料夾**。
學員常直接改範本本身（`ui/templates/`），那是唯讀區，告示牌也不算。

### 1. 把終點換成自己的圖
1. 場景樹選 `Room1` → `Goal`
2. 從 `skins/` 拖 `Skin` 到 `Goal` **底下**（子節點）
3. 把圖拖進 `Skin` 的 `texture_normal`（沒有圖可以用 `art/blocks_skin/Checkpoint_active.png`）
4. 想要踩到時換圖：另一張拖進 `texture_active`

### 2. 血條移到畫面右上角
1. `ui/templates/HudTemplate.tscn` 右鍵再製 → 拖進 `_my/`
2. 打開它，場景樹選 **`Rows`**（不是最上層）
3. Inspector「Layout」→ **Anchors Preset 選「右上」**。`Rows` 會貼到藍框右上角，內容變長時往左長
4. 存檔，回到練習關，把這個 HUD 從檔案系統拖進場景樹（放在最上層底下）
5. 常見錯誤：改了最上層 `HudTemplate` 的錨點，結果 `Rows` 超出畫面右邊；或用滑鼠拖到右上角，錨點還在左上

### 3. HUD 加一個遊玩時間
1. 打開自己的 HUD
2. 從 `ui/` 拖 `HudNumber` 到 `Rows` 底下（會自動排成新的一列）
3. `source` 選「遊玩時間」，`format` 選「分:秒」比較好看

### 4. 血量改成愛心圖示
1. 打開自己的 HUD，`Rows` → `HealthRow` 底下的 `Bar` 刪掉
2. 從 `ui/` 拖 `HudIcons` 到 `HealthRow` 底下
3. `kind` 預設就是「血量」不用改；把愛心圖拖進 `full_icon`（沒有圖可以用 `levels/_starts/_W4SkinBox/art/heart_full.png`）
4. 想要扣血後的空心：拖進 `empty_icon`

### 5. 整套 UI 換字型、配色或風格
1. 打開自己的 HUD，選**最上層**
2. `palette` 換一個（例如「糖果」），或 `style` 換一個，或把字型檔拖進 `font`
3. 常見錯誤：改了 `Icon` 色塊的顏色，那不算

### 6. 角色有待機和跑步動畫
1. 場景樹 Player → Visual 底下原本的 `Sprite2D` 刪掉，加一個 `AnimatedSprite2D`（Visual 按右鍵 → 加入子節點）
2. Inspector 的 Sprite Frames →「新增 SpriteFrames」→ 點開，下面出現動畫面板
3. 把 `default` 改名成「**待機**」，拖圖進去；新增一個「**跑步**」，拖好幾張圖進去
4. 從 `juice/` 拖 `Juice_Animator` 到 Player → Juice
5. 圖朝左畫的：`AnimatedSprite2D` 勾 Flip H
6. 圖可以用 `levels/_starts/_W4SkinBox/art/Ansimuz/` 的狐狸示範（要先在動畫面板「從精靈表新增影格」切格子）

### 7. 敵人換成會動的皮
1. 選一個 `Enemy`，從 `skins/` 拖 `SkinAnimated` 到它底下
2. Sprite Frames 新增 → 把 `default` 改名「**走路**」→ 放 **2 張以上**的圖
3. 圖可以用 `levels/_starts/_W4SkinBox/art/PixelFrog/enemy_walk.png`（精靈表，8 格）

### 8. 換成自己的暫停選單
1. `ui/templates/PauseMenuTemplate.tscn` 右鍵再製 → 拖進 `_my/`
2. 打開改排版（拖按鈕位置、改字、換配色都行）
3. 回練習關，兩種接法選一種：直接拖進場景樹，或拖進 `UISettings` 的 `pause_menu_scene`（練習關沒有 `UISettings` 的話從 `blocks/` 拖一個）

### 9. 關卡加上背景
1. 從 `skins/` 拖 `SkinBackground` 到關卡最上層底下
2. 把背景圖拖進 `texture`（可以用 `levels/_starts/_W4SkinBox/art/PixelFrog/background.png`）
3. 想要遠景慢慢動：勾 `parallax`

### 10. 整個畫面統一色調
1. 從 `skins/` 拖 `ColorGrade` 到關卡最上層底下
2. `tone` 選一個，`strength` 拉一點（預設就有強度，不改也算完成）

### 11. 零件用講師畫的圖
1. 選一個零件（例如門、按鈕、重生點），拖 `Skin` 到它底下
2. 從 `art/blocks_skin/` 把**同名**的圖拖進 `texture_normal`（例如 `Door.png`），有 `_active` 的拖進 `texture_active`
3. 練習關裡有按鈕：可以用 `Button_1.png`

### 12. 瞇眼看看主角清不清楚
1. 從 `skins/` 拖 `SquintTest` 到關卡最上層底下
2. F6 後按 **F1** 開關模糊，看主角在背景上清不清楚

### 13. 從自己的標題畫面開始
1. `ui/templates/` 挑一個標題範本右鍵再製 → 拖進 `_my/`
2. 打開它，點「開始遊戲」按鈕，`level` 下拉選**自己另存的練習關**（`_my/...`），不要選 `levels/_starts/W4_SkinPractice`
3. 存檔，在檔案系統對這個標題按右鍵 →「**設為主場景**」
4. **F5**（不是 F6）從標題開始，按「開始遊戲」進關卡，第 13 題變綠
5. 提醒學員：主場景存在 `project.godot`，重灌之後要重設一次
