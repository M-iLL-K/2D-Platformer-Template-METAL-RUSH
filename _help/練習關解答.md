# 練習關解答：W3_JuicePractice、W4_SkinPractice

給講師和助教巡場時對照，不會發給學員（`_help/` 是 `export-ignore`）。
學員版只寫「告示牌檢查什麼、常見卡住」，在 `零件手冊.md` §8。這份是完整的操作步驟。

**編輯器的四個面板**（下面步驟都用這些名字）：
- **場景面板**：左上，關卡裡所有東西排成一棵樹
- **檔案系統**：左下，專案裡的資料夾和檔案
- **Inspector**：右邊，點了某個東西之後，它的設定都在這裡
- **節點分頁**：Inspector 上方的另一個分頁，連訊號用

**拖東西的兩種地方**：
- 從檔案系統拖到**場景面板的某一行上**放開 → 變成那一行底下的子節點（縮排一層）
- 從檔案系統拖到 **Inspector 的某一格**上放開 → 那一格放進這個檔案（圖、音檔、字型）

---

## 每次都先做

1. 檔案系統 → `levels/_starts/` → 雙擊練習關（`W3_JuicePractice` 或 `W4_SkinPractice`）
2. 上方選單「**場景 → 另存場景為**」→ 對話框裡點進 `_my` 資料夾 → 檔名改成例如 `MySkinPractice.tscn` → 存檔
3. 上方分頁的名字變成新檔名，之後都改這一份
4. 做完一題：**Ctrl+S** 存檔 → 確定上方分頁是練習關 → 按 **F6**
5. 遊戲視窗開起來，天上的告示牌綠色寫「完成！」就是過了；輸出面板（下方）也會列出每一題
6. 關掉遊戲視窗回到編輯器，繼續下一題

**學員舉手說「做了沒變綠」**，先看三件事：
- 上方分頁是不是 `_my/` 那份（不是原本的 `W4_SkinPractice`）
- F6 是不是在練習關的分頁按（在 HUD、標題畫面的分頁按，跑的是那個畫面）
- 自己做的 HUD／暫停選單／標題畫面有沒有 Ctrl+S 存檔

## W3：手感果汁

所有 Juice 都放在 **Player → Juice** 底下。場景面板裡展開 `Player`（點左邊小箭頭），會看到：
```
Player
├ Visual
├ Mechanics
├ Juice        ← Juice 都拖到這一行上
└ Abilities
```

### 1. 落地時畫面震一下
1. 檔案系統 → `juice/` → 按住 `Juice_ScreenShake.tscn`
2. 拖到場景面板 **`Juice` 那一行上**放開
3. `Juice` 底下多一個 `Juice_ScreenShake`（有縮排）
4. 不用改設定：點它看 Inspector，`Timing` 已經是「落地時」
5. 存檔 → F6 → 跳起來落地，畫面會震一下

**常見錯誤**
- 拖到 `Player` 或 `Mechanics` 上：要拖到 `Juice` 上
- 拖到右邊畫面上：要拖到左上場景面板

### 2. 跳的時候有聲音
1. 檔案系統 → `juice/` → 把 `Juice_Sound.tscn` 拖到場景面板 `Juice` 那一行上
2. 不用改設定：`Timing` 預設「跳躍時」、`Sound` 預設「跳躍」
3. 存檔 → F6 → 按跳，會有聲音

**常見錯誤**
- 電腦靜音、耳機沒插：告示牌會變綠，但聽不到

### 3. 撿金幣時噴星星
1. 把 `juice/Juice_Particles.tscn` 拖到 `Juice` 那一行上
2. 點 `Juice_Particles` → Inspector：
   - `Timing` 下拉選「**撿到東西時**」
   - `Style` 下拉選「**星星**」
3. 存檔 → F6 → 去撿金幣

**常見錯誤**
- 只改了一個欄位：兩個都要改

### 4. 撿金幣時叮一聲
1. **再拖一個** `juice/Juice_Sound.tscn` 到 `Juice` 那一行上（會叫 `Juice_Sound2`）
2. 點**新的那個** → Inspector：
   - `Timing` 選「**撿到東西時**」
   - `Sound` 選「**金幣**」
3. 存檔 → F6 → 撿金幣

**常見錯誤**
- 改到第 2 題那個 `Juice_Sound`：第 4 題過了，第 2 題就變回沒完成。要兩個 `Juice_Sound`

### 5. 震得更用力
1. 場景面板點第 1 題的 `Juice_ScreenShake`
2. Inspector 找 `Strength`，拉桿往右拉到 **8 以上**（也可以直接點數字改）
3. 存檔 → F6 → 落地時震得很明顯

### 6. 打倒敵人時畫面停一下
1. 把 `juice/Juice_HitStop.tscn` 拖到 `Juice` 那一行上
2. 點它 → Inspector `Timing` 選「**打倒敵人時**」（預設是「打中東西時」，要改）
3. 存檔 → F6 → 走到敵人旁邊按 **F** 攻擊，打倒時畫面頓一下

**常見錯誤**
- `Timing` 沒改：預設「打中東西時」不算

### 7. 踩按鈕時鏡頭推近
**放 Juice**
1. 把 `juice/Juice_CameraZoom.tscn` 拖到 `Juice` 那一行上
2. 點它 → Inspector `Timing` 選「**不自動觸發**」（在下拉最下面）

**連訊號**
3. 場景面板展開 `Room1`，點裡面的 **`Button`**
4. 點 Inspector 上方的「**節點**」分頁
5. 列表裡找到 **`turned_on`**，雙擊它
6. 跳出連接視窗：在中間的節點樹點選 **`Juice_CameraZoom`**（在 Player → Juice 底下）
7. 下方「接收方法」選（或打）**`play`** → 按「**連接**」
8. 畫面上從按鈕拉出一條黃色虛線到玩家，就是連好了
9. 存檔 → F6 → 踩按鈕，鏡頭推近

**常見錯誤**
- `Timing` 沒改成「不自動觸發」：告示牌不算
- 方法選錯（不是 `play`）
- 連到別的 Juice 上

### 8. 撞牆時播自己的音效
1. 再拖一個 `juice/Juice_Sound.tscn` 到 `Juice` 那一行上
2. 點新的那個 → Inspector：
   - `Timing` 選「**撞牆時**」
   - `Sound` 選「**自訂**」→ 下面多出一格 `Custom Sound`
3. 檔案系統找到音檔，拖進 `Custom Sound`
   - 學員自己的音檔先放進 `_my/`（從 Windows 檔案總管拖進 Godot 的檔案系統 `_my/` 資料夾）
   - 沒有音檔可以先拖 `sfx/` 裡任何一個示範
4. 存檔 → F6 → 往牆壁跑

**常見錯誤**
- `Custom Sound` 空的：有黃色驚嘆號，告示牌不算
- 改到第 2、4 題那兩個 `Juice_Sound`

## W4：套皮與 UI

**再製範本**（第 2、8、13 題都會用到）：
1. 檔案系統 → `ui/templates/` → 對範本按**右鍵** →「**再製**」
2. 取一個名字（例如 `MyHud.tscn`）→ 確定
3. 新檔出現在 `ui/templates/` 裡 → **按住它拖到 `_my/` 資料夾**上放開
4. 之後都改 `_my/` 裡的那份

學員常直接改範本本身（`ui/templates/HudTemplate.tscn`），那是唯讀區，告示牌也不算。

### 1. 把終點換成自己的圖
1. 場景面板展開 `Room1`，找到 **`Goal`**
2. 檔案系統 → `skins/` → 把 `Skin.tscn` 拖到場景面板 **`Goal` 那一行上**放開
3. `Goal` 底下多一個 `Skin`（有縮排），旁邊有黃色驚嘆號（因為還沒放圖）
4. 點 `Skin` → Inspector 找到 **`Texture Normal`**（寫「空」）
5. 檔案系統把圖拖進 `Texture Normal`
   - 沒有圖可以用 `art/blocks_skin/Checkpoint_active.png`（紅旗）
6. 畫面上終點的黃色色塊不見了，換成圖；黃色虛線框是原本的碰撞範圍
7. （可以不做）踩到時換圖：另一張拖進 `Texture Active`（例如 `Checkpoint.png` 放平常、`Checkpoint_active.png` 放踩到）
8. 存檔 → F6

**常見錯誤**
- `Skin` 拖到關卡最上層或 `Room1` 上：要拖到 `Goal` 上（有黃色驚嘆號「皮要放在零件底下」）
- 圖跟虛線框對不上：點 `Skin` 直接在畫面上拖動對位置

### 2. 血條移到畫面右上角
**做自己的 HUD**
1. 照上面「再製範本」把 `ui/templates/HudTemplate.tscn` 再製到 `_my/`
2. 雙擊 `_my/` 裡的 HUD 打開，場景面板會看到：
   ```
   HudTemplate
   └ Panel       ← 要改這一層（底框）
     └ Rows
       ├ HealthRow
       └ CoinRow
   ```

**搬到右上角**
3. 場景面板點 **`Panel`**（不是最上層 `HudTemplate`，也不是裡面的 `Rows`）
4. Inspector 找到「**Layout**」區塊，展開
5. **`Anchors Preset`** 下拉選「**右上**」（Top Right）
6. 畫面上底框連同裡面的血條、金幣跳到藍色框（遊戲畫面）的右上角
7. Ctrl+S 存檔

**放進練習關**
8. 切回練習關分頁
9. 檔案系統把 `_my/` 裡的 HUD 拖到場景面板**最上層那一行**（練習關的名字）上放開
10. 存檔 → F6 → 血條在右上角

**常見錯誤**
- 改的是最上層 `HudTemplate` 的錨點：底框會超出畫面右邊
- 改的是 `Rows`：`Rows` 在底框裡面，位置由底框決定，Anchors Preset 是灰的改不了
- 用滑鼠把 `Panel` 拖到右上角：看起來對，但錨點還在左上，字變長會超出畫面
- 只在 HUD 分頁按 F6：那是在跑 HUD 自己，沒有告示牌

### 3. HUD 加一個遊玩時間
1. 打開 `_my/` 裡自己的 HUD
2. 場景面板展開 `Panel`，找到裡面的 `Rows`
3. 檔案系統 → `ui/` → 把 `HudNumber.tscn` 拖到場景面板 **`Rows` 那一行上**
4. `Rows` 底下多一列（排在 `CoinRow` 下面），畫面上多一個數字，底框自動變大
5. 點新的 `HudNumber` → Inspector：
   - `Source` 選「**遊玩時間**」
   - `Format` 選「**分:秒**」（比較好看，不選也算）
6. 存檔 → 切回練習關 → F6，數字每秒在跑

**常見錯誤**
- 拖進練習關而不是 HUD 場景裡：要在 HUD 的分頁拖
- `Source` 沒改：預設「數值」顯示金幣，不算

### 4. 血量改成愛心圖示
**打開自己的 HUD**
1. 檔案系統 → `_my/` → 雙擊自己的 HUD，上面多一個分頁
2. 場景面板會看到（看不到就點 `Panel`、`Rows`、`HealthRow` 左邊的小箭頭展開）：
   ```
   HudTemplate
   └ Panel
     └ Rows
       ├ HealthRow
       │ ├ Title     ← 寫「血量」兩個字
       │ └ Bar       ← 血條
       └ CoinRow
   ```

**刪掉血條**
3. 場景面板點 `Bar` → 按 **Delete** → 確定。畫面上只剩「血量」兩個字

**放進愛心零件**
4. 檔案系統 `ui/` → 按住 `HudIcons.tscn`，**拖到左上場景面板的 `HealthRow` 那一行上**放開
5. `HealthRow` 底下多一個 `HudIcons`，畫面上出現 3 個小方塊（還沒放圖的樣子，代表成功）

**換成愛心圖**
6. 場景面板點 `HudIcons` → Inspector 找到 **`Full Icon`**（寫「空」）
7. 檔案系統 `levels/_starts/_W4SkinBox/art/` → 把 `heart_full.png` 拖進 `Full Icon`。小方塊變成愛心
8. （可以不做）`heart_empty.png` 拖進 **`Empty Icon`**，扣血後顯示空心
9. Ctrl+S 存檔 → 切回練習關分頁（HUD 第 2 題已經拖進去了）→ F6

**常見錯誤**
- 第 4 步拖到右邊的畫面上：要拖到**左上場景面板**的 `HealthRow` 那一行
- 放開後 `HudIcons` 跟 `HealthRow` 同一層（沒有縮排）：拖到別列上了，再把它拖到 `HealthRow` 上
- 圖拖進 `Empty Icon`：放錯格，滿血時只看得到小方塊
- `kind` 預設就是「血量」，不要改

### 5. 整套 UI 換字型、配色或風格
1. 打開 `_my/` 裡自己的 HUD
2. 場景面板點**最上層**（`HudTemplate`，最上面那一行）
3. Inspector 三選一（做一個就過）：
   - `Palette` 下拉換一個，例如「**糖果**」→ 整個 HUD 的字和顏色一起變（「自訂」會多出 4 個取色器，點色塊自己選顏色；「跟標題一樣」用標題畫面的顏色，標題要先設為主場景）
   - `Style` 下拉換一個，例如「**可愛圓角**」「**木牌**」「**漫畫**」，底框和按鈕的形狀跟著變
   - 檔案系統把字型檔（`.ttf`、`.otf`、`.woff2`）拖進 `Font`
4. 存檔 → 切回練習關 → F6

**常見錯誤**
- 點了金幣旁邊的 `Icon` 色塊改顏色：那只改一個色塊，不算
- 點的不是最上層：`Palette`、`Style` 只在最上層有

### 6. 角色有待機和跑步動畫
**換成會動的圖**
1. 練習關的場景面板展開 `Player` → `Visual`，裡面有一個 `Sprite2D`
2. 點 `Sprite2D` → Delete 刪掉
3. 對 `Visual` 按**右鍵** →「**新增子節點**」→ 搜尋框打 `AnimatedSprite2D` → 選它 → 建立

**做動畫**
4. 點 `AnimatedSprite2D` → Inspector `Sprite Frames` 那格點下去 →「**新增 SpriteFrames**」
5. 再點一次那格（現在寫 SpriteFrames），下方打開「SpriteFrames」面板
6. 左邊動畫清單裡有一個 `default`：**雙擊改名成 `idle`**（叫「待機」也可以）
7. 把待機的圖拖進右邊的格子區（一張一張拖，或一次選好幾張拖）
   - 圖是一整條精靈表的話：點格子區上方「**從精靈表新增影格**」的按鈕 → 選圖 → 設定橫、直各幾格 → 全選 → 新增
   - 示範可以用 `levels/_starts/_W4SkinBox/art/Ansimuz/player_idle.png`（橫 4 格）
8. 左邊點「**新增動畫**」按鈕 → 改名成 **`run`**（或「跑步」）→ 一樣放好幾張圖（示範：`player_run.png`，橫 6 格）

**讓它自己切換**
9. 檔案系統 `juice/` → 把 `Juice_Animator.tscn` 拖到 `Player` → **`Juice`** 那一行上
10. 點 `Juice_Animator`，看「動畫」群組：`idle_animation`、`run_animation` 是（自動）就會對上；名字取得不常見的話，在下拉選對的那段
11. 存檔 → F6 → 站著播 idle、跑步播 run

**常見錯誤**
- 名字取得不常見（例如「站站」）又停在（自動）：有黃色驚嘆號「沒有待機動畫」，在 `idle_animation` 下拉選好
- 角色倒著跑：圖朝左畫的，點 `AnimatedSprite2D` 勾 **Flip H**
- 忘了拖 `Juice_Animator`：動畫不會切換，告示牌不算

### 7. 敵人換成會動的皮
1. 場景面板展開 `Room1`，找到一個 `Enemy`
2. 檔案系統 `skins/` → 把 `SkinAnimated.tscn` 拖到 **`Enemy` 那一行上**
3. 點 `SkinAnimated` → Inspector `Sprite Frames` →「新增 SpriteFrames」→ 再點一次打開下方面板
4. `default` **雙擊改名成 `walk`**（叫「走路」也可以；不改名的話 `default` 也會被當成走路）
5. 放 **2 張以上**的圖
   - 示範：「從精靈表新增影格」選 `levels/_starts/_W4SkinBox/art/PixelFrog/enemy_walk.png`（橫 8 格）→ 全選 → 新增
6. 圖太大太小：Inspector `Fill Style` 選「**拉伸蓋滿**」，自動對齊敵人大小
7. 點 `SkinAnimated` 看「動畫」群組：`normal_animation` 是（自動）就會對上；名字取得不常見就在下拉選
8. 存檔 → F6 → 敵人走路會動

**常見錯誤**
- 只放 1 格：不算「會動」
- 名字取得不常見又停在（自動）：有黃色驚嘆號「沒有走路的動畫」，在 `normal_animation` 下拉選好
- 拖到 `Room1` 上而不是 `Enemy` 上

### 8. 換成自己的暫停選單
**做自己的暫停選單**
1. 照「再製範本」把 `ui/templates/PauseMenuTemplate.tscn` 再製到 `_my/`
2. 打開它，隨便改一點：拖按鈕位置、點按鈕改 Text、點最上層換 `Palette`
3. 存檔

**放進練習關**（兩種選一種）
4. 方法 A：檔案系統把它拖到練習關場景面板的**最上層那一行**上
5. 方法 B：場景面板點 `UISettings`（沒有的話從 `blocks/` 拖一個 `UISettings.tscn` 進來）→ 把暫停選單拖進 Inspector 的 `Pause Menu Scene`
7. 存檔 → F6 → 按 **Esc** 看到自己的暫停選單

**常見錯誤**
- 再製成 HUD 範本了：要 `PauseMenuTemplate`
- 拖進 `UISettings` 的 `Hud Scene` 格：放錯格，有黃色驚嘆號

### 9. 關卡加上背景
1. 檔案系統 `skins/` → 把 `SkinBackground.tscn` 拖到場景面板**最上層那一行**上
2. 點 `SkinBackground` → 把背景圖拖進 Inspector 的 `Texture`
   - 示範：`levels/_starts/_W4SkinBox/art/PixelFrog/background.png`
3. 背景會自動鋪滿整個關卡、放在最後面
4. （可以不做）勾 `Parallax`，遠景會慢慢跟著動
5. （可以不做）只想蓋一部分：`Cover Area` 選「自己拉範圍」，拉 `Width In Tiles`、`Height In Tiles`；
   或選「所在的房間」，再把背景拖到某個 `Room` 底下，只蓋那個房間
6. 存檔 → F6

**常見錯誤**
- `Texture` 空的：有黃色驚嘆號
- 拖到 `Player` 上：要放在最上層底下（`Cover Area` 選「所在的房間」時才放到 `Room` 底下）
- `Cover Area` 選了「所在的房間」卻放在最上層：有黃色驚嘆號，會先蓋整個關卡

### 10. 整個畫面統一色調
1. 檔案系統 `skins/` → 把 `ColorGrade.tscn` 拖到場景面板**最上層那一行**上
2. 畫面馬上偏暖色（預設「暖」、強度 0.5）
3. （可以不做）`Tone` 換一個（冷、復古、夜晚），`Strength` 拉桿調強弱
4. 存檔 → F6

**常見錯誤**
- `Strength` 拉到 0：看不出效果，告示牌不算
- 放了兩個：有黃色驚嘆號，刪掉一個

### 11. 零件用講師畫的圖
1. 場景面板展開 `Room1`，選一個零件，例如 **`Button`**
2. 檔案系統 `skins/` → 把 `Skin.tscn` 拖到 **`Button` 那一行上**
3. 點 `Skin` → 檔案系統 `art/blocks_skin/` → 把 **`Button_1.png`** 拖進 `Texture Normal`
4. 存檔 → F6

`art/blocks_skin/` 的檔名就是零件名稱：`零件名.png` 放 `Texture Normal`，`零件名_active.png` 放 `Texture Active`（例如 `Door.png`、`Door_active.png`）。

**常見錯誤**
- 圖是從別的資料夾拖的（例如 `_my/`）：這題要用 `art/blocks_skin/` 的圖
- 用了 `SkinAnimated`：這題檢查的是 `Skin`

### 12. 瞇眼看看主角清不清楚
1. 檔案系統 `skins/` → 把 `SquintTest.tscn` 拖到場景面板**最上層那一行**上
2. 存檔 → F6 → 遊戲中按 **F1**：畫面變模糊，再按一次恢復
3. 看模糊時還找不找得到主角；找不到就是主角跟背景太像，要換顏色

**常見錯誤**
- 按 F1 沒反應：輸出面板看有沒有「已啟用」；在匯出的遊戲裡不會作用（只在編輯器 F5／F6 有效）

### 13. 從自己的標題畫面開始
**做自己的標題**
1. 照「再製範本」把 `ui/templates/` 裡任一個標題範本（`TitleScreenTemplate`、`_Center`、`_Side`）再製到 `_my/`
2. 打開它，點最上層 → Inspector 填 `Game Name`（遊戲名稱）、`Hook`（一行小字），`Key Art` 拖一張主視覺（都可以不填）

**設定開始遊戲去哪**
3. 場景面板找到「開始遊戲」按鈕（在 `Layout` → `Bottom` → `Buttons` 底下，叫 `Start`）
4. 點它 → Inspector `Level` 下拉選**自己另存的練習關**（`_my/MySkinPractice.tscn`）
5. 存檔

**設成主場景**
6. 檔案系統對 `_my/` 裡的標題按**右鍵** →「**設為主場景**」
7. 按 **F5**（不是 F6）：從標題畫面開始 → 按「開始遊戲」→ 進到練習關，第 13 題變綠

**常見錯誤**
- `Level` 選到原本的 `levels/_starts/W4_SkinPractice`：要選 `_my/` 裡自己那份
- 按 F6：F6 是跑目前分頁，不會從標題開始；這題要 F5
- 把標題拖進關卡裡：標題是獨立的場景，會被自動拿掉並有中文警告
- 重灌之後：主場景存在 `project.godot`，重灌會掉，要再「設為主場景」一次

**（可以不做）配色**：主視覺換成自己的主角後顏色不搭，標題最上層 `Palette` 選「**跟主視覺配**」自動配，`Tone`、`Main Color` 換著看；
HUD、暫停選單的 `Palette` 選「**跟標題一樣**」，整套同一套顏色
