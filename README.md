# 五週遊戲原型工作坊

你只需要做三件事：**拖節點、選下拉選單、拉數值拉桿**。不用寫程式。

忘記快捷鍵、不知道訊號要連什麼、不知道卡片怎麼操作 → 看 **`速查表.md`**。
東西放在哪個資料夾、每個零件有哪些設定、按鍵設定和房間怎麼用 → 看 **`零件手冊.md`**。
完整的操作手冊（線上版）→ 👉 https://app.notion.com/p/0-1-0921803c84a4821cb24101829d07081b

> 選單名稱後面的英文是 Godot 英文介面的原名，找不到中文選項時照英文找。

## 1. 安裝（第一次）

1. 下載 **Godot 4.7.2**（Windows 64-bit，**不要**選 .NET 版，也**不要**用更新的版本）
   👉 https://godotengine.org/download/archive/4.7.2-stable/
2. 解壓 Godot，直接執行 `Godot_v4.7.2-stable_win64.exe`（不用安裝）
3. 解壓這個專案壓縮檔到任意資料夾
4. Godot 專案管理員 → **匯入**（Import）→ 選專案資料夾裡的 `project.godot` → **匯入並編輯**（Import & Edit）
5. 第一次開啟會跑一陣子匯入進度條，等它跑完再動

---

## 2. 資料夾規則

| 資料夾 | 能不能改 |
|---|---|
| `_my/` | ✅ **你的東西全部放這裡** |
| 其他所有資料夾 | ❌ 只能看、只能拖，**不要改、不要存檔進去** |

存檔時看一下路徑是不是 `res://_my/...`。存到別的地方，重灌時就會不見。

## 3. W1 上課流程

1. **抽卡**：打開 `levels/CardDraw.tscn` → 按 **F6** → 按「抽卡」
2. **逛展示間**：打開 `levels/Showroom.tscn` → 按 **F6**，看看各種零件怎麼動
3. **另存玩具箱**：打開 `levels/_starts/W1_ToyBox.tscn` → **場景 → 另存場景為**（Scene → Save Scene As）→ 存到 `_my/`
   （之後都改 `_my/` 裡的這份，不要改原本那份）
4. **拖東西進去**（見第 5 節）
5. **調數值**：點節點 → 右邊 Inspector 拉拉桿、選下拉選單。滑鼠停在欄位上會有中文說明
   （玩家的跑速、跳多高、重力：點 **Player**，看「移動參數」；跳躍好不好按：看「按鍵手感」）
6. **試玩**：按 **F6**（執行目前場景）

### 3.1 W3：手感果汁（Juice）

1. **先感受差別**：打開 `levels/_starts/W3_JuiceBox.tscn` → 按 **F6** → 從頭跑到終點，途中按 **0** 把全部 Juice 關掉／打開對照
2. 回到自己的關卡（`_my/` 裡那份；W3 才加入的話，把 `W3_JuiceBox` 另存到 `_my/`）
3. **拖 Juice**：從 `juice/` 拖到 **Player → Juice** 底下，不調任何東西就有效果
4. **選什麼時候播**：點那個 Juice → Inspector 的 `timing` 下拉（跳躍時、落地時、受傷時、打倒敵人時…）
5. **想在卡片、零件的事件播**：`timing` 選「不自動觸發」，再把卡片或零件的訊號連到這個 Juice 的 `play`
   （例：重力翻轉卡的 `flipped` → `Juice_ScreenShake` 的 `play`；做法跟按鈕開門一樣）
6. 同一種 Juice 可以拖好幾個，各選不同的時機（例：一個跳躍音效、一個撿金幣音效）
7. **背景音樂**：拖 `Juice_BGM`，把自己的音樂檔（放在 `_my/` 底下）拖進 `music`，一開場就播。
   想換歌就多放幾個、各放一首，用 `timing` 或訊號連到想播的那個的 `play` 切換

每個 Juice 有哪些設定 → `零件手冊.md` §6。

**練習關**：打開 `levels/_starts/W3_JuicePractice.tscn` → **場景 → 另存場景為** 存到 `_my/` → 照天上 8 塊告示牌的題目拖 Juice（做了沒變綠看 `零件手冊.md` §8）、
改設定 → 按 **F6**，做對的告示牌會變綠色寫「完成！」（輸出面板也會列出每一題）。

**按鍵手感**（不是 Juice，在 **Player** 的 Inspector「按鍵手感」）：晚一點按也能跳、早一點按也能跳、短按小跳、頂頭修正、起跑加速，
每一項都可以勾選開關。想感受差別：全部取消勾選玩一次，再全部勾回來玩一次。

### 3.2 W4：套皮與 UI

1. **先看換完長什麼樣子**：打開 `levels/_starts/W4_SkinBox.tscn` → 按 **F6**（HUD、暫停選單、過關畫面、零件、角色、背景都換過了）；
   標題畫面打開 `levels/_starts/_W4SkinBox/ui/TitleDemo.tscn` → 按 **F6** → 按「開始遊戲」
2. 回到自己的關卡（W4 才加入的話，把 `W4_SkinBox` 或 `W3_JuiceBox` 另存到 `_my/`）
3. 自己的圖片、字型都放在 `_my/` 底下（例如 `_my/art/`）
4. **用了別人的素材要記下來**：寫在 `_my/CREDITS.txt`，格式和授權怎麼看 → `零件手冊.md` §7

**換零件外觀**：在關卡裡點選零件（終點、門、敵人、金幣…）→ 從 `skins/` 拖 `Skin` 進去當它的子節點 → 把圖拖進 `texture_normal`。
- 黃色虛線框是原本色塊的範圍，碰撞不會跟著圖變，圖要畫在框裡（可以直接拖動 `Skin` 對位置）
- 狀態改變後的樣子（門打開、按鈕亮起、終點踩到…）拖進 `texture_active`；沒放就用平常的圖變色
- 要動畫：拖 `SkinAnimated`，在 Sprite Frames 做動畫（名字隨便取），在「動畫」群組下拉選平常（敵人是走路）、狀態改變後各播哪段；取 idle、walk、active 這類常見名字會自動對上
- 找不到零件的圖：`art/blocks_skin/` 有講師畫的，檔名就是零件名稱（`Door.png` 放 `texture_normal`、`Door_active.png` 放 `texture_active`）
- 想讓別的東西觸發換圖（例如按按鈕讓終點的旗子升起）：按鈕的訊號連到皮的 `show_active`；兩張以上的圖放 `more_textures`，連 `next_look` 一張一張換

**換 HUD**：`ui/templates/HudTemplate.tscn` 按右鍵 **再製**（Duplicate）→ 存到 `_my/` → 打開改（拖位置、換圖、加零件選數值）→ 把它拖進關卡。
範本裡的 `Panel` 是底框，血條金幣都在裡面；要搬到右上角就選 `Panel`，Layout 的 Anchors Preset 選右上。字還是看不清楚的話，最上層的 `hud_background` 選「字加外框」（預設就是）。
**換暫停選單／過關畫面**：`PauseMenuTemplate`、`ClearScreenTemplate` 一樣再製到 `_my/` 改好，拖進關卡裡 `UISettings` 的欄位
（關卡沒有 `UISettings` 的話從 `blocks/` 拖一個）。整套字型、配色、風格：點畫面最上層，改 `font`、`font_size`、`palette`（10 套；選「自訂」會出現 4 個取色器，自己配；選「跟標題一樣」就用標題畫面那套顏色）、`style`（7 種：像素復古、乾淨極簡、可愛圓角、木牌、科幻、漫畫、復古遊戲機）。
素材顏色兜不起來：從 `skins/` 拖 `ColorGrade` 進關卡，選色調、拉強度，整個畫面就會統一成同一種氣氛。

**加背景**：從 `skins/` 拖 `SkinBackground` 進關卡，圖拖進 `texture`。`cover_area` 決定蓋多大：整個關卡（預設）、所在的房間（把背景拖到某個 Room 底下，每個房間可以不一樣）、自己拉範圍。
範圍小的會自動蓋在上面，所以「整個關卡一張＋某個房間換一張」直接放就好。

**做標題畫面**：`ui/templates/` 裡三個標題範本（`TitleScreenTemplate` 上中下三段、`_Center` 主視覺當背景、`_Side` 左文右圖）挑一個
右鍵**再製**到 `_my/` → 點最上層填 `game_name`、`hook`，把主視覺圖拖進 `key_art`（也可以直接點裡面的字和圖改）→
點「開始遊戲」按鈕，在 `level` 下拉選自己的關卡 → 在 `_my/` 裡的標題上按右鍵 **設為主場景**。
按 **F5** 就從標題開始；過關畫面、暫停選單的「回標題」會自動出現。標題畫面不要拖進關卡，它自己就是一個場景。
範本已經有「設定」鍵：按了打開設定頁（音量、手機按鈕），按「返回」或 Esc 回來。設定頁平常是藏著的，想在裡面加東西（例如作弊的勾選框）：
點場景樹上 `SettingsPage` 旁邊的**眼睛**打開，把東西拖進 `Center/Panel/List`。之前就再製過的標題沒有設定鍵：從 `ui/` 拖 `SettingsPage` 進標題最上層底下，
再複製一顆按鈕、`action` 選「打開設定」。
放了主角的主視覺不知道怎麼配色：標題最上層的 `palette` 選「**跟主視覺配**」，從圖自動配顏色（`tone` 換深底／淺底、`main_color` 換主色）；
想自己挑就選「自訂」，用取色器的滴管吸主視覺的顏色（口訣見 `零件手冊.md` §7.2）。HUD、暫停選單、過關畫面的 `palette` 選「跟標題一樣」，整套 UI 就同一套顏色。
標題要有音樂：音樂檔拖進最上層的 `music`（換關時自動淡出）。按鈕要有音效：最上層「按鈕音效」群組的 `press_sound`（按下）、`select_sound`（選到）下拉選一個，
整個畫面的按鈕都會響；某顆想不一樣就在那顆按鈕（`MenuAction`）的「音效」群組自己選。暫停選單、過關畫面也一樣。

**手機也能玩**：從 `ui/` 拖 `TouchControls` 進關卡，畫面上就有左、右、跳、暫停四顆手機按鈕（電腦上會自己藏起來，`show_on` 選「一直顯示」可以用滑鼠點來測）。
要攻擊鍵就另外拖一顆 `TouchButton`，`press` 選「鍵盤按鍵」、`key` 選跟能力一樣的鍵。想用搖桿走路：拖 `TouchStick`，套件開「可編輯的子節點」把 Left、Right 的「可見」取消勾。
讓玩家自己決定要不要手機按鈕：把 `TouchSwitch` 拖進標題畫面或暫停選單（選的結果會記住）。

**換角色**：Player → Visual 底下的 `Sprite2D` 換成 `AnimatedSprite2D`，在 Sprite Frames 做站著、跑步、跳起、落下的動畫
（名字隨便取，取 idle、run 這類常見名字會自動對上）→ 從 `juice/` 拖 `Juice_Animator` 到 **Player → Juice**，每個狀態在下拉選播哪段。
還可以選落地、轉向、撞牆這類一次型動畫，調跑多快才算跑步，見 `零件手冊.md` §7.3。圖朝左畫的，在 `AnimatedSprite2D` 勾 **Flip H**。

**換地形**：`art/terrain_tile.tres`（會自動接邊的地形圖塊）右鍵再製到 `_my/` → 照 `art/tile_template.png` 的格子畫自己的圖（每格 16×16，
放大版說明看 `art/tile_template_guide.png`）→ 點再製的圖塊集，把圖拖進去取代原本的圖片 → 關卡的 `TileMapLayer` 換成自己的圖塊集。
畫地形時在圖塊面板選「地形」（Terrains）分頁，選「地面」或「平台」用筆刷刷，邊會自動接好。
用網路下載的圖塊（排法跟範本不一樣）：要自己設接邊規則，見 `零件手冊.md` §7.4「進階」。

**背景圖**：從 `skins/` 拖 `SkinBackground` 進關卡（放最上層底下）→ 把圖拖進 `texture`。預設「重複鋪滿」自動鋪滿所有房間，
永遠在所有東西後面，不用管場景樹順序。一張大圖用「拉伸蓋滿」；想要遠景（鏡頭移動時背景動得比較慢）就勾 `parallax`、拉 `depth`。

每個零件有哪些設定 → `零件手冊.md` §7；動畫名稱 → `速查表.md` §6。

**練習關**：打開 `levels/_starts/W4_SkinPractice.tscn` → **場景 → 另存場景為** 存到 `_my/` → 照天上 13 塊告示牌的題目做（關卡比較長，往右走看後面的題目；做了沒變綠看 `零件手冊.md` §8）→
按 **F6**，做對的告示牌會變綠色。第 13 題（標題畫面）要把標題的「開始遊戲」選成你另存的這一關，再把標題設為主場景。

### 3.3 額外功能：作弊模式

**給玩家的秘技**：從 `cheats/` 拖 `Cheat` 進關卡 → Inspector 勾要開什麼（「開關類」：無敵、不會死、飛行、穿牆、無限跳、遊戲速度、敵人凍結、鏡頭拉遠；
「一次性」：加數值、換房間、在這裡設重生點、直接過關）。預設在遊戲裡依序按 **W W S S A D A D**（上上下下左右左右）就會打開，再按一次關掉；
`code` 可以改成自己的指令（只能打英文字母和數字）。想放在暫停選單讓玩家勾：`unlock_by` 選「選單勾選框」，把 `Cheat` 拖進暫停選單的按鈕清單底下。
想要更多組秘技就多拖幾個 `Cheat`，各打不同的指令。

**給自己測關卡**：從 `cheats/` 拖 `DevCheats` 進關卡，按 F6 後按 **`**（Tab 上面那顆鍵）打開清單，按 1～9、-、= 開關（不會死、飛行穿牆、換房間…）。
只在編輯器裡有效，匯出網頁版給別人玩時自動失效，不用記得拔掉。完整說明看 `零件手冊.md` §9。

## 4. 建立自己的關卡

要做一個真正給別人玩的關卡時：

1. 打開 `levels/_Template.tscn`
2. **什麼都還沒改之前**，先按 **場景 → 另存場景為**（Scene → Save Scene As）→ 存到 `_my/`，取個名字（例如 `MyLevel.tscn`）
   - 跟第 3 節玩具箱的做法一樣。上方分頁變成你取的名字，之後改的、存的都是 `_my/` 裡這份
   - 先改了才另存的話，按 Ctrl+S 會存回原本的模板，重灌就不見了
3. 在 `_my/` 裡那份上按右鍵 → **設為主場景**（Set as Main Scene）
   - 做了標題畫面的話，改成把**標題**設為主場景，關卡在標題的「開始遊戲」按鈕選（見 §3.2「做標題畫面」）
4. 之後按 **F5** 就會直接跑你的關卡（或標題），匯出網頁版也是從這裡開始

> 重灌專案後主場景會跑掉，要重做第 3 步。

> ⚠ **不要用檔案總管（Windows 的資料夾視窗）複製 `.tscn` 檔**，也不要從同學那裡直接複製關卡檔過來。
> 檔案總管複製出來的檔案跟原本那份用同一個編號，Godot 會把兩個當成同一個檔案，
> 結果「設為主場景」按了沒反應、改到的是別份。要複製一律在 Godot 裡用「另存場景為」。

## 5. 東西要拖到哪裡

從左下角「檔案系統」把 `.tscn` 拖到左上角「場景」樹上：

```
你的關卡
├── Player
│   ├── Mechanics   ← mechanics/ 的機制卡（抽到的那張）
│   ├── Juice       ← juice/ 的手感組件
│   └── Abilities   ← abilities/ 的攻擊能力（近戰、遠程）
├── RespawnHandler  ← 死掉後讓你重生（範本已經放好，刪掉就不會重生）
├── Room1、Room2…   ← blocks/Room.tscn（房間，見下面 5.1）
├── GameFlow        ← blocks/GameFlow.tscn（遊戲流程：遊戲開始、玩家死亡、過關…每個事件都是一個訊號，挑想要的連出去）
├── EventListener   ← blocks/EventListener.tscn（只聽一個事件，可以延遲幾秒再發訊號）
├── ValueSettings_Health ← blocks/ValueSettings.tscn（血量設定，見下面 5.2）
├── KeySettings     ← 所有按鍵：改左右上下、跳躍，以及自己加的按鍵（見下面 5.3）
│   └── Key_…       ← blocks/KeyTrigger.tscn（自訂按鍵，一個一列）
└── （直接放在關卡底下） ← blocks/ 的零件（按鈕、門、風扇、敵人…）
```

- **拖錯位置不會壞**，輸出面板會跳出中文提示告訴你該放哪
- 不想要了 → 選取節點按 **Delete**
- 想暫時關掉 → Inspector 取消勾選 `enabled`
- **暫停選單**每一關都有，不用拖：遊戲中按 **Esc** 或 **P**，可以調主音量／音效／音樂、整關重來、離開遊戲

### 5.1 怎麼拖一個房間

關卡比一個畫面大時，把它切成一格一格的房間：玩家走進哪個房間，鏡頭就直接跳到那個房間；
在哪個房間死掉，就在那個房間重生，只有那個房間的箱子、敵人、金幣會復原。

1. **先開格線吸附**（每台電腦設一次）：中間畫面上方工具列打開 **格線吸附**（Use Grid Snap，磁鐵旁的格子圖示），
   再到 **吸附選項 → 設定吸附**（Configure Snap）把 **格線步長**（Grid Step）設成 **16 × 16**
2. 從 `_Template.tscn` 另存的關卡已經有一個對齊畫面的 **Room1**（淺藍色的框）。自己的關卡沒有的話，
   把 `blocks/Room.tscn` 拖到關卡底下，框的**左上角**對齊畫面左上角
3. 框太大或太小 → Inspector 拉 `width_in_tiles`／`height_in_tiles`（30 × 17 格剛好一個畫面）
4. 要第二個房間 → 選取 Room 按 **Ctrl+D** 複製，拖到第一個框的**旁邊**，邊跟邊貼齊，不要重疊也不要留縫
5. 框裡的**黃點**是重生位置。想換位置 → 在 Room 底下加一個 `Marker2D`，把它拖到你要的地方

> 有放重生點（Checkpoint）的關卡，**一定要拖 Room**。沒有 Room 的話，重生點之前撿過的道具
> 死掉後會再出現，可以重複撿。

### 5.2 調血量、金幣等數值

範本已經放好一個 **ValueSettings_Health**，點它在 Inspector 拉 `start_value`（一開始幾滴血）、`max_value`（最多幾滴）。

其他數值（金幣、鑰匙、分數…）也一樣：從 `blocks/` 拖一個 `ValueSettings.tscn` 進關卡，`kind` 打上數值的名字
（例如「金幣」，這是全專案**唯一要打字**的地方，打錯字輸出面板會提醒），再調下面的欄位：

| 欄位 | 用途 |
|---|---|
| `start_value` / `max_value` | 一開始多少、最多多少（0 代表不限） |
| `show_in_hud` | 打勾：一開場就顯示在左上角；不勾：不顯示 |
| `reset_on_death` | 死掉時要不要退回（累計分數這種就關掉） |

### 5.3 按鍵設定

範本已經放好一個 **KeySettings**。

**改基本操作**：點它，在 Inspector「預設操作」的下拉選單選新的按鍵：

| 欄位 | 預設 |
|---|---|
| `left_key` / `right_key` / `up_key` / `down_key` | A / D / W / S |
| `jump_key` | 空白鍵 |

- 選 **None** = 不改，維持預設
- **方向鍵永遠都能用**，改的只是字母鍵和空白鍵
- 設定存在你的關卡裡，重灌也不會不見（要綁手把等其他裝置，看下面的「進階：Input Map」）
- 選到跟卡片或其他動作一樣的鍵，輸出面板會提醒

**加自己的按鍵**（例如按 E 開門）：

1. 把 `blocks/KeyTrigger.tscn` 拖到 **KeySettings 底下**，改個好認的名字（例如 `Key_OpenDoor`）
2. Inspector：`key_source` 預設就是「自訂按鍵」，`key` 選 E；`trigger` 選什麼時候觸發（按下時／放開時／按住時）
3. 右邊「**節點**」分頁 → 雙擊 `triggered` → 選門 → 函式選 `toggle` → 連接
4. 要再加一個 → 選它按 **Ctrl+D** 複製，再改名字、按鍵、連線

**進階：Input Map（綁手把等其他裝置）**

上面的下拉選單只能選鍵盤和滑鼠。要用手把，到「專案 → 專案設定 → **Input Map**」：

- **基本操作**：點 `jump`、`move_left` 這些動作右邊的 **+**，按一下手把上的按鈕就加好了，不用改其他地方
- **卡片、能力**：上面先加一個新動作（例如 `attack`）並綁好按鍵或手把按鈕；
  再到卡片的 Inspector，「按鍵種類」選 **Input Map 動作**，下面出現的 `action` 選剛剛加的動作
- **按鍵觸發器**：`key_source` 選「跟基本操作同一顆鍵」，`same_key_as` 也能選你加的動作

⚠ Input Map 存在專案設定裡，**不在 `_my/`**：重灌（第 7 節）之後要**重新加一次**，加了什麼先記下來。
別把 `jump`、`move_left` 原本的按鍵刪光，刪光的話一按 Play 輸出面板會提醒你。

## 6. 沒反應怎麼辦

1. **先看下方「輸出」面板**：⚠ 開頭的中文訊息會告訴你哪裡有問題
2. 常見狀況：

| 狀況 | 原因 |
|---|---|
| 拖進去沒效果 | 放錯位置，對照第 5 節 |
| 按鍵沒反應 | 同一顆鍵被兩個東西綁了，輸出面板會寫是哪兩個 |
| 攻擊看起來沒打中 | 擊退力道（`knockback`）設成 0，敵人被打中也不會動 |
| 死掉之後不會重生 | 關卡裡沒有 `RespawnHandler`，從 `blocks/` 拖一個進來 |
| 沒有聲音 | 按 **Esc** 打開暫停選單，看主音量／音效／音樂是不是被拉到 0 |
| 背景音樂沒播 | `Juice_BGM` 的 `music` 是空的（場景樹上有黃色驚嘆號），或兩個都勾了 `play_on_start`（只會播第一個） |
| 走到某個地方鏡頭突然跑掉 | Room 被 Scale 縮放過（場景樹上有黃色驚嘆號）：Scale 改回 1，用 `width_in_tiles`／`height_in_tiles` 拉大小 |
| 鏡頭不會跟著換房間 | 關卡裡沒有 `Room`，或兩個 Room 之間留了縫，對照第 5.1 節 |
| 套了皮還是顯示色塊 | `Skin` 的 `texture_normal` 沒放圖，或 `SkinAnimated` 的 `normal_animation` 沒選到動畫；看場景樹上的黃色驚嘆號 |
| 角色不會動、不會轉身 | 沒有拖 `Juice_Animator` 到 Player → Juice，或 `idle_animation` 沒選到動畫；也可能按過 **0** 把 Juice 關掉了 |
| 角色倒著跑 | 圖是朝左畫的：在 Visual 底下的 `AnimatedSprite2D` 勾 **Flip H**（敵人的皮也一樣） |
| 自己的 HUD 沒出現 | HUD 要拖進關卡（或放進 `UISettings` 的 `hud_scene`）；同一種畫面只能放一個 |
| 地形邊緣接不起來 | 用的是一般筆刷，改到圖塊面板的「地形」分頁選「地面」再刷 |
| 改完沒變化 | 忘了存檔（**Ctrl+S**）再按 F6 |
| 「設為主場景」按了沒反應 | 這份關卡是用檔案總管複製來的。在 Godot 打開它 → **場景 → 另存場景為** 存一份新名字，對新的那份設主場景，確認沒問題再刪舊的 |
| 更新後輸出面板一堆 `invalid UID … using text path instead` | 不影響遊玩，打開自己的關卡存一次就會消失 |

還是不行再舉手 🙋

## 7. 重灌／更新專案

專案壞掉，或講師發了新版時。**有用 GitHub 的人看 7.2。**

### 7.1 沒用 GitHub

1. 把 `_my/` 整個資料夾**複製**到桌面
2. **刪掉**整個專案資料夾
3. 解壓新的專案壓縮檔
4. 把桌面的 `_my/` **貼回**專案裡，問要不要取代時選 **全部取代**
5. 用 Godot 重新匯入（同第 1 節步驟 4）
6. 重新設定主場景（第 4 節第 3 步）。沒設之前，`palette` 選「跟標題一樣」的 HUD、選單會有黃色驚嘆號、先用預設配色
7. 有改過 Input Map 的話，重新加一次（第 5.3 節「進階：Input Map」）

大約 30 秒。

### 7.2 有用 GitHub

⚠ **不能刪整個資料夾**：裡面有個隱藏的 `.git` 資料夾，刪掉就跟你的 GitHub repo 斷線了。

1. GitHub Desktop 先 **Commit + Push**（這就是備份）
2. 打開專案資料夾，刪掉**除了 `.git` 和 `_my` 以外**的所有東西
3. 新版壓縮檔解壓到這個資料夾，遇到重複選 **取代**
4. 用 Godot 開啟，等匯入跑完，重新設定主場景（第 4 節第 3 步）
5. GitHub Desktop 會列出這次更新改了什麼 → **Commit + Push**

**第一次建 repo 時**
- GitHub 網頁問要不要加 `.gitignore` → 選 **None**（專案已經有了）
- 在學校電腦：每次上課用 GitHub Desktop **Clone** 下來，下課前 **Commit + Push**，然後**登出** GitHub Desktop

## 8. 匯出網頁版（給別人玩）

### 8.1 安裝匯出範本（每台電腦只要做一次）

1. 上方選單 **編輯器 → 管理匯出範本**（Editor → Manage Export Templates）
2. 按 **下載並安裝**（Download and Install，檔案約 1 GB，要等一下）
   - 講師有給 `.tpz` 檔的話 → 改按 **從檔案安裝**（Install from File）→ 選那個檔案，比較快
3. 看到 `4.7.2.stable` 顯示「已安裝」就完成

### 8.2 匯出

1. 確認主場景是你的關卡（第 4 節）
2. **專案 → 匯出**（Project → Export）
3. 左邊選 **Web**（已經設定好，不用改任何東西）
4. 按 **匯出專案**（Export Project）→ 確認「**匯出時包含除錯**」（Export With Debug）**沒有勾** → **存檔**
5. 檔案會出現在專案資料夾的 `build/web/`

> ⚠ 直接雙擊 `index.html` **打不開**，這是正常的。要上傳到網站才能玩。

### 8.3 上傳到 itch.io

1. 把 `build/web/` **裡面的所有檔案**壓成一個 zip（`index.html` 要在 zip 最外層）
2. itch.io → **Upload new project** → Kind of project 選 **HTML**
3. 上傳 zip → 勾選 **This file will be played in the browser** → 把 `_my/CREDITS.txt` 的內容貼到頁面說明（Description）→ 存檔
4. 分享網址給別人
